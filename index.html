🔐 Kebijakan Privasi

Data yang kami kumpulkan

Dompetku hanya mengumpulkan data yang Anda masukkan sendiri: nama akun Google, transaksi keuangan (nominal, kategori, tanggal, keterangan), pengaturan anggaran, dan preferensi kategori.

Di mana data disimpan

Semua data disimpan di Firebase Firestore milik Anda sendiri, terisolasi per akun Google. Data tidak pernah dibagikan ke pihak ketiga manapun. Tidak ada server eksternal yang menerima data Anda.

Keamanan

Akses ke data dilindungi oleh Firebase Security Rules — hanya akun Google Anda yang bisa membaca dan menulis data Anda. Koneksi selalu menggunakan HTTPS/TLS.

Penghapusan data

Anda bisa menghapus seluruh data kapan saja melalui Firebase Console atau dengan menghubungi pengembang. Logout tidak menghapus data — data tetap tersimpan untuk sesi berikutnya.

Analitik & iklan

Dompetku tidak menggunakan analytics tracker, pixel iklan, atau layanan pihak ketiga lain selain Firebase (Google) dan Google Fonts. Tidak ada iklan.
